OPEN INVITATION — GITHUB PAGES SETUP
=====================================

FILES (all in the root; no folders):
- index.html       Website pages and invitation layout
- style.css        Visual design and responsive layout
- script.js        Open Invitation button, falling gold glitter, and music controls
- cover.png        First page cover image
- invitation.png   Second page invitation image
- birthday-song.mp3 Music file
- README.md        These setup instructions

UPLOAD TO GITHUB:
1. Download and extract this ZIP.
2. Upload all seven files directly into the root of your GitHub repository.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then click Save.
6. Wait for GitHub Pages to publish the site.

HOW IT WORKS:
- Tap the Open Invitation area on the cover.
- The second invitation page appears.
- Gold glitter begins falling.
- Music attempts to play after the tap. Mobile browsers generally require a user gesture before audio playback.
- The music button at the bottom pauses/resumes playback.

NOTE:
Only publish the music if you have permission to use it.
